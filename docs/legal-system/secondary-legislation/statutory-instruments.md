# Statutory Instruments

Secondary legislation fills in the operational detail Parliament leaves to
Regulations under powers granted in the Acts (see
[Primary legislation](../primary-legislation/acts/tma-1970.md)). There is no
single small set of SIs that matters for Self Assessment - they get made or
amended continually - so rather than trying to mirror all of them, this
wiki:

- Fully mirrors the small number of SIs that are structurally central to
  Self Assessment (procedure, not substantive tax rules) - see below.
- Links directly to the live search for everything else, since a snapshot
  of "SIs matching 'tax'" goes stale immediately and isn't something a
  static mirror should pretend to keep current.

## Live search

[statutoryinstruments.parliament.uk - search "tax"](https://statutoryinstruments.parliament.uk/?SearchTerm=tax)

## Mirrored SIs

- [Tribunal Procedure (First-tier Tribunal) (Tax Chamber) Rules 2009](tribunal-procedure-ftt-tax-chamber-rules-2009.md)
  - Governs how a Self Assessment appeal actually proceeds once it reaches
    the tribunal: time limits, case categorisation, evidence, costs.

To add another SI to the mirrored set, add a `type: legislation` entry to
`pipeline/sources.yml` pointing at its `legislation.gov.uk` contents page -
see [How this wiki stays current](../../meta/refresh-process.md).
